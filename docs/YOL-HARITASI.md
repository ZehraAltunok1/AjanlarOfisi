# Yol haritası — Noonwire pilotu

- [x] **Faz 1 — Temel:** anayasa, ajan kimliği, kayıt formatı, blog takımı (iş tarifi, kurallar, kaynaklar), 5 alt ajan.
- [x] **Faz 2 — Tasarım araştırması:** ödüllü editoryal/blog sitelerinin incelenmesi → 2–3 tasarım yönü → Zehra seçer.
- [x] **Faz 3 — Blog sitesi:** Astro, Brief + Deep Dive şablonları, arşiv, etiketler, RSS, karanlık/aydınlık, i18n'e hazır.
- [x] **Faz 4 — İlk deneme koşusu:** elle "günlük koşuyu başlat" → taslaklar → bekçi → Zehra onayı → sitede görünür.
- [x] **Faz 5 — Ofis ekranı:** yerel sayfa; ajan masaları, durum ışıkları, teslimler, zaman çizelgesi, defter.
- [ ] **Faz 6 — Zamanlayıcı:** her gün 12:00 otomatik koşu (masaüstü uygulaması zamanlanmış görevi).
- [ ] **Faz 7 — 2 hafta gözlem:** kabul oranı, takılma noktaları, kural güncellemeleri, haftalık değerlendirme.
- [ ] **Sonra:** Vercel'de yayın · Türkçe sürüm · Kariyer, Web Sitesi, Routez departmanları.
